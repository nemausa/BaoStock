  rebound_top3 策略 — 最终交易规则（经2021-2026年数据回测验证）
════════════════════════════════════════════════════════════════

一、选股规则（每个交易日收盘后执行）
────────────────────────────────────
1. 排除 名称中含"ST"的股票
2. 用 7% 作为趋势切换阈值
3. 历史验证（至少1次同类事件）：
   - 历史高点→低点 回撤幅度在 27%～33%
   - 低点后最高反弹达到 20% 以上
4. 当前事件：
   - 当前高点→当前低点 回撤在 27%～33%
   - 当前收盘价距当前低点的反弹 ≤ 5%（尚未大幅拉起）
5. 换手率 ≥ 5%
6. 按 rank_score 排序，只取第1名（rank1）
   ⚠ 不使用第2、第3候选；若无满足条件股票，当天不操作
7. 【核心】信号广度 ≥ 2：当日通过上述全部过滤的候选股必须 ≥ 2 只才交易
   ⚠ 若当日只有 1 只（或 0 只）满足条件 → 全天空仓不操作
   含义：要求市场级别的"共振见底"，而非孤立信号。这是收益提升的关键——
   孤立信号（仅1只见底）在弱市中极不可靠，2025/2026 的亏损主要来自这类信号。

二、入场规则（次日早盘开盘时确认）
────────────────────────────────────
次日（T+1）开盘后，查看该股实时开盘价：

  开盘幅度 = (开盘价 / 昨收) - 1

  只有一条判断规则：

  ┌──────────────────────────────────┬─────────────────────────┐
  │           开盘情况                │         操作            │
  ├──────────────────────────────────┼─────────────────────────┤
  │ 低开超过 2%（幅度 < -2%）         │ 跳过，今晚重新扫描选股  │
  │ 其余所有情况（含平开、低开≤2%、   │ ✓ 买入                  │
  │ 任意高开）                        │                         │
  └──────────────────────────────────┴─────────────────────────┘

  跳过后 → 当晚重新运行选股脚本 → 次日再判断新 rank1

三、仓位管理
────────────────────────────────────
- 同时最多持有 1 只股票
- 全仓操作（可用现金买满整手，每手100股）
- 初始本金建议：5万元起（可等比例缩放）

四、出场规则
────────────────────────────────────
持仓期间每天开盘判断（优先级：止损 > 止盈 > 到期）：

  止损：买入价 × 0.96（-4%）
  止盈：买入价 × 1.10（+10%）
  到期：最长持有 15 个交易日，到期按当日收盘价卖出

  跳空执行规则（重要）：
  - 若某天开盘价 ≤ 止损价 → 以开盘价立即卖出（实际亏损可能 > 4%）
  - 若某天开盘价 ≥ 止盈价 → 以开盘价立即卖出（实际盈利可能 > 10%）
  - 日内触碰止损/止盈线 → 以止损/止盈价成交

五、再入场限制
────────────────────────────────────
- 卖出当日：不可买入任何股票，次日起才可买
- 同一股票：卖出后 10 个交易日内不重复买入（冷却期）

六、日常操作流程
────────────────────────────────────
每天收盘后：
  1. 运行 ./strategy_recommended_runner/run_daily_rebound_top3.sh
  2. 查看输出的候选股（换手率≥5%, 回撤≤33%）
  3. 【关键】确认"过滤后候选数 ≥ 2 只"——
     若只有 1 只或 0 只 → 明日空仓，不操作（脚本会提示"信号孤立，不操作"）

次日早盘（仅当广度达标时）：
  4. 确认当前手上无持仓（或持仓已卖出）
  5. 查看 rank1 实时开盘价，计算开盘幅度
  6. 若低开超过 2% → 跳过，今晚重新扫描
     否则 → 买入

八、本次优化的核心逻辑（为什么收益提升）
────────────────────────────────────
1. 【信号广度≥2 是关键】经数据分析，rank_score 对"已选中交易"无区分力，
   换任何其他排序字段都更差，故选股逻辑不变。真正的问题在"孤立信号"：
   2025/2026 弱年大量出现"全市场仅 1 只股票见底"的情况，这类信号极不可靠。
   要求当日 ≥ 2 只共振见底后，2025 从 +17% 跃升至 +134%，2026 从 -11% 转为 +57%。

2. 【出场放宽】信号质量提高后，止盈 8%→10%、持仓 10→15 天让利润奔跑，
   止损 3%→4% 减少被正常波动扫损；二者叠加把累计从 +708% 提升到 +1017%。

九、注意事项
────────────────────────────────────
1. 每日务必先确认"信号广度≥2"，仅 1 只信号时严格空仓等待，这是纪律性要求。

2. 回测已扣除标准交易手续费；实际佣金因券商而异（万1~万3），若你的佣金更低，
   实际收益会高于上表；滑点、停牌、涨跌停无法成交等因素未模拟。

3. 策略基于历史数据验证，不代表未来必然盈利。
